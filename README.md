# COSMOS

COSMOS is a research-oriented framework for automatically generating domain-oriented test inputs from program path constraints. Its main DomainSolver component processes constraint files, extracts source-level information, classifies constraints by domain, and applies specialized solving steps for boolean, numeric, string/char, and array-related conditions, while the included benchmark collections support experimentation and evaluation across different constraint types.



### Papers

This repository is based on the following paper:

A. Kalaee, S. Parsa, and N. Fathi, “COSMOS: A Comprehensive Framework for Automatically Generating Domain-Oriented Test Suite,” *Information and Software Technology*, vol. 154, p. 107091, Feb. 2023, doi: [10.1016/j.infsof.2022.107091](https://doi.org/10.1016/j.infsof.2022.107091).
